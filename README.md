# Archery Score Recorder

> A web app for recording and tracking archery scores, backed by a SQL database.

![Type](https://img.shields.io/badge/type-university%20project-blue)

---

## Overview

A web app for recording and tracking archery scores, backed by a SQL database. This repository describes the project at a high level. The source code is not public (see below).

## The Problem

Recording and totalling archery scores by hand is slow and easy to get wrong, and it is hard to look back at past results.

## Why I Built It

Built to practise full-stack development: designing a database, writing server-side code and building the interface people use.

## Key Features

- Record scores through a web form
- Store results in a SQL database
- View saved scores later

## How It Works

1. A user enters scores in a web form
2. PHP validates the input and saves it to the database
3. Saved scores are queried and shown back to the user

## What I Learned

- Designing database tables and queries
- Connecting a PHP backend to a database
- Validating user input
